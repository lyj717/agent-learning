# Python 7 天补齐清单（有编程基础专用）

> 前提：你已经在别的语言里会写代码（变量、循环、函数、类的基本概念都懂）。
> 目标：7 天内具备「读得懂 Agent 项目源码、写得出工具函数和 API 调用」的 Python 水平。
> 总投入：约 30~35 小时。第 8 天起直接进入 Agent 主线，边做边补。

---

## 核心原则：不要系统学，要针对性补

你需要的不是「Python 全貌」，而是**能读懂并改写 Agent 项目的那 20% 语法**。判断标准很具体：

- 看到一段真实的 LangGraph 或 API 调用代码，你能逐行说出它在干嘛。
- 能自己写出一个函数，让模型调用它并拿到结果。

**明确不要做的事**
- 不要买一套 40 小时的 Python 视频课从第一集看到最后一集。
- 不要学 GUI、爬虫框架、Django、Flask 全栈、数据分析全家桶。
- 不要背标准库。用到了再查。
- 不要追求「学完再动手」。这个清单本身就是动手。

**明确要做到的事**
- 每天至少写 100 行代码，不看教程盲敲。
- 遇到不懂的语法，直接问 AI：「这段代码逐行解释给我，并说明和我熟悉的语言有什么差别」。这是你最快的学习方式，别客气。
- 每天结束把代码 push 到 GitHub。

---

## Day 1｜语法迁移（3~5 小时）

**目标**：把「用别的语言的思维写代码」改成「用 Python 写代码」，消除最初的别扭感。

**必学**
- 缩进即语法：没有大括号，冒号 + 缩进块。这是新手第一天的最大绊脚石。
- 动态类型、变量不需要声明、没有分号。
- `print()` 与 f-string：`f"{name} 有 {count} 条记录"`（这个你后面每天要用几十次）。
- 条件与循环：`if / elif / else`、`for x in items`、`while`、`range()`。
- `and / or / not`（不是 `&&`、`||`、`!`）。
- 真值判断：哪些值被视为 False（`None`、`0`、`""`、`[]`、`{}`）。
- 空值 `None`（不是 `null` / `nil`）。
- 缩进用 4 个空格，绝对不要混用 Tab。

**练习**
1. 读一个整数，判断它是奇数还是偶数，各自打印出来。
2. 用 for 循环打印菲波那契前 20 项。
3. 写一个函数，接收一个字符串列表，返回其中最长的那个。

**验收**：写代码时不再下意识打大括号和分号。

---

## Day 2｜容器与推导式（4~5 小时）

这一天的内容决定了你后面读代码会不会卡住，务必写熟。

**必学**
- `list`、`dict`、`tuple`、`set` 四种容器的区别与选用场景。
- 下标与切片：`arr[0]`、`arr[-1]`、`arr[1:3]`、`arr[::-1]`。
- 字典操作：`d["k"]` vs `d.get("k", 默认值)`、`d.keys()`、`d.items()`、`d.update()`。
- **推导式**（高频，务必练熟）：`[x*2 for x in nums]`、`[x for x in nums if x > 0]`、`{k: v for k, v in d.items()}`。
- 解包：`a, b = 1, 2`、`first, *rest = items`、`f(**kwargs)`。
- 常用函数：`len`、`sum`、`sorted`（含 `key=lambda`）、`enumerate`、`zip`、`any`、`all`。
- 深浅拷贝的区别：`a = b` 只是同一个对象的另一个名字（这是刷 bug 的高发区）。
- 不可变类型：`tuple`、`str`（字符串不可就地修改，只能生成新的）。

**练习**
1. 给定一串消息字典（`role` / `content`），过滤出所有角色是 `user` 的内容并拼成一个字符串。
2. 统计一段文本里每个词出现的次数，按次数从高到低输出前 5 个。（提示：`Counter` 可以用，但先用字典手写一遍）
3. 把一个嵌套的 JSON 结构（列表套字典）拍平成列表。

**验收**：能用一行推导式替代 5 行循环。

---

## Day 3｜函数与类型注解（4~5 小时）

**必学**
- 函数的定义、默认参数、关键字参数调用。
- **可变默认参数的陷阱**：`def f(a=[])` 会让你痛一次，必须理解为什么。
- `*args` 与 `**kwargs` 的用途（读框架源码时会大量遇到）。
- `lambda`、函数作为参数传入（`sorted(key=...)`、`map`、`filter`）。
- **类型注解**：`def search(query: str, top_k: int = 5) -> list[dict]`。
  - 这是 Agent 开发的重中之重，因为工具的入参 schema 直接来自这里。
  - 要会写：`str`、`int`、`float`、`bool`、`list[str]`、`dict[str, Any]`、`str | None`。
- `dataclass`（比手写 `__init__` 简洁，读代码常见）。
- 作用域与 `global`（知道即可，写出 `global` 通常意味着设计有问题）。

**练习**
1. 写一个函数 `search(query, top_k=5, filters=None)`，返回模拟的检索结果列表。
2. 给这个函数补全类型注解，用 `None` 而不是可变对象做默认值。
3. 用 `sorted(key=lambda x: x["score"], reverse=True)` 对结果排序并取前 N 条。
4. 故意写一个可变默认参数的函数，调用两次，观察它「记住」了上一次的数据，写下原因。

**验收**：能解释为什么工具函数的类型注解会影响模型的行为。

---

## Day 4｜类、模块与 Pydantic（4~5 小时）

**必学**
- 类的基本结构：`class`、`__init__(self, ...)`、`self` 的含义、实例属性与方法。
- 继承与 `super().__init__()`（了解即可）。
- 特殊方法：`__str__`、`__repr__`、`__len__`（看到不慌就行）。
- 模块与导入：`import x`、`from x import y`、`if __name__ == "__main__":` 的作用。
- **Pydantic**（重点）：用 `BaseModel` 定义数据结构、自动校验、`.model_dump()` 转字典。
  - 这是 Agent 开发里定义工具参数和结构化输出的标准做法，务必练熟。
- 枚举 `Enum`（用来表示固定的状态或选项）。
- `@property` 装饰器（知道是什么即可）。

**练习**
1. 定义一个 `Message` 类，含 `role` 和 `content` 两个字段，打印时显示成人类可读的格式。
2. 用 Pydantic 定义 `ToolCall` 模型（含工具名、参数字典），从一段 JSON 字符串解析出来。
3. 故意传一个非法类型进去，观察 Pydantic 报的错，理解「校验」的价值。

**验收**：能独立用 Pydantic 描述一个工具的入参结构。

## Day 5｜文件、异常、环境与包管理（4~5 小时）

**必学**
- 文件读写：`with open(...) as f:` 的写法。理解 `with`（上下文管理器）为什么能自动关文件。
- `pathlib.Path`：路径拼接和遍历目录比字符串拼接安全得多。
- JSON 处理：`json.loads` / `json.dumps`（含 `ensure_ascii=False`、`indent=2`）。
  注意区分「JSON 字符串」和「Python 字典」，这是新手最容易混淆的一点。
- 异常处理：`try / except / finally`、捕获具体异常而不是一把抓、`raise` 主动抛出。
- **虚拟环境与包管理**：`venv` 或 `uv`，`pip install`，`requirements.txt` vs `pyproject.toml`。
  - 每个项目一个独立虚拟环境，永远不要在系统 Python 里装东西。
- 环境变量：`os.environ`、`python-dotenv` 读 `.env`，密钥绝不写进代码。
- 日志：用 `logging` 而不是满屏 `print`（你后面调试 Agent 全靠它）。

**练习**
1. 读一个本地 JSON 文件，改一个字段，写回到新文件。
2. 写一个函数读 API Key：优先读环境变量，没有就抛一个自定义异常。
3. 新建一个虚拟环境，装 `httpx`、`pydantic`、`python-dotenv`，确认版本。

**验收**：能自己从零建一个干净的项目环境，密钥不落盘。

## Day 6｜生成器、装饰器与 async（5~6 小时）

**必学**
- 迭代与生成器：`yield` 的作用（流式输出就靠它，必须懂）。
- **装饰器**：理解 `@app.get("/chat")` 这种写法背后是什么（函数被包装了）。
  - 只需要会读和会用现成的，不需要自己写复杂的装饰器。
- **异步**（重要）：
  - `async def` / `await` 的含义，为什么网络请求要用异步。
  - `asyncio.gather` 并发发起多个请求（Agent 里并行调工具就靠它）。
  - `async for` 处理流式响应（模型逐字返回的核心写法）。
  - 理解「异步适合 IO 密集，计算密集靠多进程」，不必深挖 GIL。
- 单线程模型下为什么异步更快：等待网络时不阻塞其他任务。

**练习**
1. 写一个生成器函数，逐个 `yield` 出一句话的字符（模拟流式输出）。
2. 用 `asyncio.gather` 并发请求 3 个网址，打印各自耗时和总耗时，对比改成串行后的差距。
3. 读一个真实的流式 API 示例代码（模型厂商官方文档里都有），逐行注释。

**验收**：能说清「流式输出为什么能让用户感觉更快」。

## Day 7｜串烧实战（5~6 小时）

把 6 天所学拼成一个能拿出手的小工具，这一天直接对应你主线第 1 周的任务。

**要做的**
1. 命令行参数解析：用 `argparse` 或 `typer` 接收用户输入。
2. 用 `httpx` 调用一次模型 API（真实调用，不是模拟）。
3. 用 `dotenv` 读密钥，用 `logging` 打日志。
4. 用 Pydantic 定义一次请求结构。
5. 支持流式打印模型回复。
6. 写至少 1 个 `pytest` 测试（测试参数拼装或输出解析这类纯逻辑）。
7. 用 `ruff` 格式化一遍代码，push 到 GitHub，写一个像样的 README。

**验收标准（很硬）**
- 换一台机器，照着 README 能在 5 分钟内跑起来。
- 你能对着自己的代码连续讲 3 分钟不卡壳。

## 8 天之后的持续补齐策略

Python 不可能 7 天学完，剩下的用「刚好够用」的方式补：

| 时机 | 你会被迫学会的东西 |
|---|---|
| 第 1~2 周调 API | 参数传递、异常处理、JSON 处理 |
| 第 3 周手写循环 | 类设计、状态管理、生成器 |
| 第 4 周用框架 | 装饰器、依赖注入、类型注解 |
| 第 5~6 周做 RAG | 文件处理、批量操作、向量运算的基本概念 |
| 第 7 周做成服务 | async、FastAPI、并发与超时 |
| 第 8 周写测试 | pytest、mock、CI 配置 |

**遇到不认识的语法时的标准动作**
1. 先猜一遍语义（你已经会编程，猜中率通常不低）。
2. 写 5 行代码验证你的猜测。
3. 猜错就问 AI：「这行的作用是什么？为什么会这样设计？」并把它记进 `python-notes.md`。
4. 每周重读一次这份笔记。

这不是「抄捷径」，而是让学习顺序跟着需求走。Python 的语法细节会在你写完 2000 行真实代码后自然补齐——前提是你先动手，而不是先学完。
