## 每个项目的 README 必备

1. 一句话说明解决谁的什么问题
2. 架构图
3. 运行方式（照抄能跑起来）
4. 关键取舍与数据（成本、延迟、准确率）
5. 已知缺陷与下一步

真实轨迹与短讲解随阶段保留；正式演示视频在面试复习时补录。JD 与简历按学员安排在学习项目结束后统一处理。实验必须注明样本量、判分口径和设置，不能把教学模拟数据写成线上业务成果。
