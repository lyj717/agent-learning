## Day 37：切成片段后，怎样仍能找到原文

**预计半个自然日，约 1.5～2.5 小时**，包括复习 Day 36 的加载与来源字段、读两份
演示、独立实现 A/B、跑边界情境、填写四道短观察及订正。本周仍以约 4 个自然日完成
为目标；今天只引入“固定行窗口与重叠”这一主要机制，继续使用已有 Python 和
`langchain-core==1.6.10`，无需安装新的切分包。

今天的产出是能把全文变成一组带原始位置的片段。每段最多几行叫 `chunk_lines`，
相邻段共享几行叫 `overlap_lines`；步长是两者之差。原文行号从 1 开始且包含两端，
Python 切片下标从 0 开始、不包含右端；五行全文在窗口 3、重叠 1 时只有第 1～3、
3～5 行，第一次到文末就停止，不再补一段 5～5 行。

片段仍是 `Document`，返回接口写在练习 A 的题干里：`id` 区分片段，`source` 指向
原文件，`line_start/line_end` 记录原文范围。片段正文按所选原行用换行重新连接，
内部空行和两侧空格保留；原文末尾的换行不额外追加，不承诺字节原样保留。
按行窗口易于核对来源，但不能保证字符或 token 上限，单行过长的边界会在检查入口展示。

复看入口（本单元已完成当次验收）：

1. 用 5～10 分钟回看自己 Day 36 的 `load_sources`，确认它交回的是全文和相对来源。
2. 运行并读 [行窗口演示](demos/day37/day37_line_window_demo.py)：学窗口、步长、重叠和文末停止。
3. 运行并读 [片段来源演示](demos/day37/day37_chunk_source_demo.py)：学片段编号与原始行范围。
4. 运行 [Day 37 成品练习](exercises/day37_chunks_exercises.py)：A 批量切分，B 核对来源、范围和正文；
   函数题干已清为一行 docstring，主程序对照输出与学员末尾回答原稿保留。

所有命令从仓库根目录运行：
