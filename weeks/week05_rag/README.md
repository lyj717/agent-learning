# Week 05｜RAG 基础

**交付物**：对自己资料库的问答 Agent，答案必须带引用出处。

## 必做顺序

- [ ] 文档加载 → 切分 → 向量化 → 存储 → 检索 → 生成
- [ ] 先用一种切分策略，保存文档、片段与来源位置的对应关系
- [ ] 选一个向量库（Chroma / Qdrant / pgvector）
- [ ] 答案带引用与出处；检索不到时明确说「没找到」
- [ ] 学员准备约 10 条「问题 + 期望来源/无答案」的小样本，保存改动前基线；AI 不代填期望答案
- [ ] 分开检查检索命中、答案内容和引用是否支持结论

先使用可直接读取的文本或文本型 PDF。只选一个向量库跑通，不安排多个库的重复搭建；具体读哪些官方文档，在开工搭教具时给出对应版本、网址和章节。

## 选修

第二种切分策略、多轮追问与指代改写、扫描件解析。混合检索与重排在 Week 06 根据失败类型选用。

## 验收标准

- [ ] 能比较当前资料规模下全量输入与检索的成本、效果、更新和权限取舍
- [ ] 能指出当前方案最薄弱的一环在哪
- [ ] 用新问题分清检索未命中、生成答错和引用不支持结论；没有来源时不编答案
