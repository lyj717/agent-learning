3. HTTPException 演示里两份响应正文相同，状态码为什么不同？
   客户端只检查 JSON 中有没有 detail，能否判断这次 HTTP 请求是否成功？

   作答：因为两份响应分别路由到了不同的函数，一个普通返回，另一个raise  HTTPException，并且设状态码为404
