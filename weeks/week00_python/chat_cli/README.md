## 它由哪几块组成

```
chat_cli/
├── chat_cli.py       命令行入口：接参数、配日志、把各块串起来
├── llm.py            和模型打交道：拼请求、发请求、解析回复
├── tests/test_llm.py 测试（测 llm.py 里的纯逻辑）
└── pytest.ini        测试配置（让测试能 import 到 llm.py）
```

分成两个文件是有意的：`llm.py` 不碰命令行、不打印任何东西，
所以它容易被测试；`chat_cli.py` 只管和「人」打交道。
