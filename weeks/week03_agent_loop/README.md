# Week 03｜Agent 核心循环（手写）

**规则**：这一周不许用框架。自己写主循环、自己解析模型输出、自己决定终止条件。

**交付物**：不用任何框架的 ReAct Agent。

## 清单

- [ ] 理解「思考 → 行动 → 观察」的循环
- [ ] 设计终止条件：拿到答案 / 达到最大步数 / 超时或超预算
- [ ] 自己写主循环与输出解析
- [ ] 接 3 个工具：检索、计算器、沙箱执行
- [ ] 完整日志：每步的思考、工具调用、观察结果都打印
- [ ] 加最大步数与成本上限

## 验收标准

- [ ] 能说清「为什么框架会掩盖 bug」
- [ ] Agent 在工具连续报错时不会无限循环
