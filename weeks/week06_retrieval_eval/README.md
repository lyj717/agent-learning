### 字段与判分规则

| 字段 | 含义与核对规则 |

## Day 43：检索指标与判分口径

本次只有一个主要新机制：**把检索结果与预先标注的相关项比较，并明确分母**。
判分单位固定为唯一片段编号；固定资料快照与切分，不等同于事实覆盖率。

| 指标 | 单题口径 |
|---|---|
| Hit@k | 前 k 条至少有一个标注相关项为 1，否则为 0 |
| Recall@k | 前 k 条中的相关项数 / 全部标注相关项数 |
| Precision@k | 前 k 条中的相关项数 / k，返回不足 k 条仍用 k |
| 无答案样本 | 仅限已经确认原文没有答案的题；三指标为 None；其中检索仍返回至少 1 条片段的，每题另计 1 次 |
| 跨题平均 | 先算每题指标，再只对有答案题平均；没有有答案题时为 None |

相关标签从原文确定，不能只看返回结果反推。未标注不能冒充无答案。
片段级 Recall 不保证所有必要事实都覆盖；切分变了，旧片段标签也不能原样套用。
Day 44 会保留原文位置和事实依据，并明确版本映射；真实基线的检索、回答、引用分别核对。
