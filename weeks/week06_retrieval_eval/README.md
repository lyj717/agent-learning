### 字段与判分规则

| 字段 | 含义与核对规则 |
|---|---|
| id、split | id 是题号；split 是题目的分组，与文本切块无关。保留 q01～q24 dev、q25～q30 holdout，不按运行好坏换组 |
| question | 根据固定全文提出的问题，避免只把已有题换几个词 |
| answerable | 原文能回答填 true；确认没有所问信息填 false；尚未标完保留 null |
| expected | true 时写回答必须覆盖的要点；false 时写原文缺少什么，不能推测答案 |
| evidence | true 时填写依据的 source、line_start、line_end；false 时为 [] |

每处 evidence 的形状见演示；同题需要几处不同依据，就写几个范围。
evidence 标原文位置，不是逐个填写候选片段：同一处原文被多个重叠块覆盖，只标一次，
相关片段编号由 A 生成；不同原文位置各自提供有效依据时，分别记录。
行号为整数、从 1 起、包含两端，尽量标能证明要点的精确行，不能把全文整段标成依据省事。
单看主题相关不等于能回答；未标注的 null 不计入无答案。
新增二十题包含单处依据、多处组合和无答案情境，两组都保留可回答与无答案情境，
范围按实际原文选择；格式校验不会替你完成这些人工判断。

A 的固定规则是**同一 source，依据与片段至少共享一行即算相关**，允许部分相交，包含端点；
只返回匹配片段编号的 set，不把依据行范围直接当片段编号。同源重叠块都可相关，重复命中只收一次。
相关片段可能只带有一部分依据或重复同一事实，因此本次片段 Recall 不等于事实覆盖率。
若后续选择改变切分，须按相同原文依据重新映射标签，并补核对依据覆盖；不能只凭片段 Recall 选切分。

开发组可以在后续反复看结果调方案；留出组先准备并标注，冻结方案后再查效果。
同一事实的两种问法不算独立事实覆盖。若以后看了留出结果又据此调整方案，应记录该组已参与调参，
再补新检查。今天没有留出题的检索或评分入口，validate 仅检查格式与行号。

## Day 43：检索指标与判分口径

本次只有一个主要新机制：**把检索结果与预先标注的相关项比较，并明确分母**。
判分单位固定为唯一片段编号；固定资料快照与切分，不等同于事实覆盖率。

| 指标 | 单题口径 |
|---|---|
| Hit@k | 前 k 条至少有一个标注相关项为 1，否则为 0 |
| Recall@k | 前 k 条中的相关项数 / 全部标注相关项数 |
| Precision@k | 前 k 条中的相关项数 / k，返回不足 k 条仍用 k |
| 无答案样本 | 仅限已经确认原文没有答案的题；三指标为 None；其中检索仍返回至少 1 条片段的，每题另计 1 次 |
| 跨题平均 | 先算每题指标，再只对有答案题平均；没有有答案题时为 None |

相关标签从原文确定，不能只看返回结果反推。未标注不能冒充无答案。
片段级 Recall 不保证所有必要事实都覆盖；切分变了，旧片段标签也不能原样套用。
Day 44 会保留原文位置和事实依据，并明确版本映射；真实基线的检索、回答、引用分别核对。
