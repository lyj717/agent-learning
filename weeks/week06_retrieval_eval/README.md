# Week 06｜高级检索与检索评测

**交付物**：分层指标报告 + 至少一组控制变量的对比实验。没有提升也是有效结果。

## 必做顺序

- [ ] 从 Week 05 样本逐步扩展到 30~50 条，学员标注期望来源与无答案情境
- [ ] 留出一部分不参与反复调参的问题；报告调参样本与留出检查各自的数量和结果
- [ ] 定义 Hit@k、Recall@k、Precision@k 的判分单位与分母；分开看检索、答案、引用、成本与延迟
- [ ] 根据失败类型，从切分调整、混合检索、重排等方法中选一项，固定其他条件做前后对比
- [ ] 涉及不同用户数据时，在数据进入模型前执行权限约束，并检查跨用户泄露
- [ ] 根据结果决定保留、回退或继续优化，说明收益与代价

## 选修

第二、三组有依据的对比实验；查询改写、多查询、HyDE、父子块、上下文压缩、时间加权与 nDCG。不要为了勾选目录把每种方法都接一遍。

## 验收标准

- [ ] 能用数据说明改动影响了哪类问题；没有改判分口径、没有把调参样本当作未见过的新问题
- [ ] 能解释一个没改善的案例，以及下一步该查检索还是生成
