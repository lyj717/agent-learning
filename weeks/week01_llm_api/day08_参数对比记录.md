## 2. 观察（用自己的话回答）

1. temperature=0 时，5 次答案完全一样吗？和你原来的预期一致吗？
不完全一样（5 次出了 3 种）。原因：这个模型默认开着思考模式，官方文档写明
temperature「思考模式下不生效」，所以设成 0 也不保证每次一样。

补充实验（换 prompt「给我起个名字，姓刘」再跑一轮）：0.0 和 1.5 两边的表现
完全一致——每次都是 finish=length、1024 个 token 全被思考吃掉、正文为空。
同一件事、两个温度、结果一模一样，这本身就说明温度在思考模式下不起作用。
2. temperature=1.5 相比 0.0，主要不一样在哪？举一条你觉得最「离谱」或最意外的输出。
输出更加多样化，三日天气通
3. 每次调用花了多少 token？这些 token 主要花在「回答」上，还是别的地方？

## 4. 你踩的坑 / 意外

让模型起名字时每次都 finish=length：输出 1024 个 token 全是思考，正文为空。
max_tokens 从 512 调到 1024 照样被吃光——开放式任务会让它一直想下去。

## 5. 一句话结论

temperature是一个控制模型输出的参数，在0—2之间。参数越低，模型越沉稳，适合固定的，严谨的工作；参数越高，模型越发散，适合随机的，需要创意的工作。
