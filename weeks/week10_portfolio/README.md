# Week 10｜作品集定型

## 三个项目

| 项目 | 展示能力 | 硬性要求 |
|---|---|---|
| 复杂工具型 Agent | 工具设计、循环控制、错误恢复 | 3 个以上真实工具、失败重试、trace 截图 |
| 企业知识库问答 | RAG 全链路、评测意识 | 带引用、有评测集、有对比实验数据表 |
| MCP Server 或开源小工具 | 工程规范、社区意识 | 有测试、有 CI、清晰 README、issue/PR 记录 |

## 每个项目必须包含

- [ ] 一句话说明「解决谁的什么问题」
- [ ] 架构图
- [ ] 3 分钟以内的演示录屏或在线 demo
- [ ] 关键取舍说明：为什么不选另一个方案，成本与延迟如何
- [ ] 已知缺陷与下一步计划
