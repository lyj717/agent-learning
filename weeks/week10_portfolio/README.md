# Week 10｜作品集定型

## 两个主要项目 + 一个小工具

整理已有成果，不在这一阶段新建三个同等规模的系统。日常保留运行轨迹和讲解要点；正式视频按学员安排在面试复习时补录。

| 项目 | 展示能力 | 硬性要求 |
|---|---|---|
| 复杂工具型 Agent | 工具设计、循环控制、错误恢复 | 能执行的工具、失败路径、trace；标清真实/模拟数据 |
| 文档知识库问答 | RAG 全链路、评测意识 | 带引用、有评测集、至少一组有依据的对比实验 |
| MCP Server 或已有能力拆出的小工具 | 工程规范、复用能力 | 相关测试、CI、清晰 README；有实际 issue/PR 再展示 |

## 每个项目必须包含

- [ ] 一句话说明「解决谁的什么问题」
- [ ] 架构图
- [ ] 真实运行方式与讲解提纲；正式视频面试复习时补录，至少一个主要项目能供他人体验
- [ ] 关键取舍说明：为什么不选另一个方案，成本与延迟如何
- [ ] 已知缺陷与下一步计划
