# Week 09｜进阶方向（只选一项完成）

先完成前面的核心项目与回归检查，再选择一个有实际用途的方向。其余选修不作为本阶段门槛；JD 与简历仍按学员安排在学习项目结束后统一处理。

## 选项

- [ ] **A｜MCP**：写一个自己的 MCP Server（接文件/数据库/某个 API），发布到 GitHub，写好 README
- [ ] **B｜多智能体**：研究员 + 批评者 + 汇总者的协作流程，每步 trace 可展示
- [ ] **C｜语音/实时**：实时语音链路、打断处理、延迟预算
- [ ] **D｜微调与蒸馏**：了解 SFT、LoRA 的流程与代价，知道大多数业务问题不该靠微调解决

MCP 可复用此前的文件检索或数据库工具；若选其他方向，小工具也优先从已有能力中拆出。选择 D 时先核对数据、算力和可验收范围，仅阅读概念不能算完成该方向的可用成果。

## 验收标准

- [ ] 至少一个方向做到「别人可以用」的程度，而不是只跑通 demo
